# Roadmaps - Guías de Aprendizaje

Colección de guías y recursos para aprendizaje de tecnologías modernas.

## Contenido

- **nestjs-roadmap/** - Roadmap interactivo con seguimiento de progreso para el curso NestJS de Fernando Herrera (Udemy)
- **nestjs-guide/** - Guía de referencia modular con código, notas y ejemplos por sección del curso

## Secciones del curso NestJS

1. Primeros pasos en Nest
2. DTOs y Validación de información
3. Nest CLI Resource - Brands CRUD
4. Generar build de producción básico
5. MongoDB Pokedex
6. Seed y Paginación
7. Variables de entorno - Deployment y Dockerizar
8. TypeORM - Postgres
9. Relaciones en TypeORM
10. Carga de archivos
11. Autenticación y autorización
12. Documentación - OpenAPI
13. Websockets
14. Desplegar toda la aplicación a producción
15. Despedida del curso

## Cómo usar

- **nestjs-roadmap**: abre `index.html` en el navegador, marca lecciones completadas y rastrea tu progreso.
- **nestjs-guide**: abre `index.html` para navegar el contenido por sección con ejemplos de código.
