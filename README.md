# Roadmaps - Guías de Aprendizaje

Colección de guías y recursos para aprendizaje de tecnologías modernas.

## Contenido

- **nestjs/** - Roadmap y guías para NestJS framework

## Estructura

Cada carpeta contiene recursos organizados por tecnología:
- Guías de aprendizaje
- Roadmaps visuales
- Ejemplos de código
- Recursos de referencia

## Cómo usar

Navega las carpetas para encontrar la tecnología que deseas aprender. Cada guía incluye pasos progresivos desde conceptos básicos hasta tópicos avanzados.
